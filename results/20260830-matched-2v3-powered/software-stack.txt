WHY THIS FILE EXISTS

Driver version is a first-class performance variable on GB10, not background
detail. r0b0tlab/deepseek-v4-flash-nvfp4-gb10-benchmark documents a ~3.5x
throughput regression between driver 580.142 and 580.159.03 on this hardware.

Consequence:
  - INTERNAL validity of this bundle is unaffected. Both arms ran the same
    driver in the same session, so node count remains the only variable.
  - EXTERNAL comparability requires this file. A tok/s number from another
    Spark cluster cannot be compared to ours without knowing both drivers.

Anyone quoting numbers from this bundle should quote the driver alongside.
Anyone comparing their own numbers to ours should state theirs.
